# 🔐 Gerador de Senhas Seguras

Aplicação desktop desenvolvida em Python utilizando Tkinter para gerar senhas fortes e personalizadas.

## Funcionalidades

- ✅ Geração de senhas aleatórias
- ✅ Escolha do tamanho da senha
- ✅ Letras maiúsculas e minúsculas
- ✅ Números
- ✅ Caracteres especiais
- ✅ Indicador de força
- ✅ Copiar para área de transferência
- ✅ Interface gráfica

## Tecnologias

- Python 3
- Tkinter

## Como executar

```bash
python main.py
```

## Preview

Exemplo:

- Senha gerada: `D@9hPx!7aL2#`
- Força: 🟢 Forte
